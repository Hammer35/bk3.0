HTML-ФАЙЛЫ КУРСА ДЛЯ СТУДИИ html-video

В папке 42 HTML-файла: один файл = один урок = источник для отдельного короткого видео.
00-ОГЛАВЛЕНИЕ.html — кликабельное оглавление.

Как делать ролики:
1. Откройте студию html-video и создайте проект.
2. Прикрепите один файл урока (например, 01-1.html) в поле чата.
3. Отправьте такой запрос:

Создай короткое вертикальное видео на русском по прикреплённому уроку. Возьми содержание и факты только из файла. Сделай понятный сценарий с 3–5 сценами: вопрос или ситуация, объяснение, практический шаг. Сохрани оговорки и точные определения; не добавляй неподтверждённые цифры, обещания результатов или факты о Pinterest. Используй читаемый русский текст на экране, крупную типографику и спокойную анимацию. В конце оставь один практический вывод. Не добавляй музыку или озвучку.

4. Просмотрите результат, при необходимости поправьте текст сцен и нажмите Export MP4.
5. Для следующего ролика создайте новый проект или очистите чат/проект, затем приложите следующий урок.

Файлы — это структурированные источники с исходным содержанием уроков, а не готовые MP4 и не HTML-анимации для прямого экспорта. Для генерации нужен работающий агент в студии. Если снова появится «Invalid API key», сначала авторизуйте выбранный агент (например, Claude Code через /login) или переключите студию на авторизованный Codex CLI.

Примечание: уроки опираются на исходный курс pinterest_course_russian_final.md. Ссылки на справку Pinterest сохранены.
