# BOOSTKLIENT®

## Language

**Сессия ИИ-стратега**: непрерывная переписка одного пользователя с ИИ-стратегом, привязанная к одному бизнесу. Заголовок сессии формируется из первого вопроса пользователя.

**Карта сессии**: упорядоченный список вопросов пользователя в одной сессии. Каждый пункт ведёт к соответствующему сообщению этой переписки.
