Прочитай CONTEXT-005.md. Предложи компактную замену enforce_source_honesty и необходимых regex. Требования:
1. Нельзя удалять «Не обещай покупателю вещь, которой нет ни у кого.»; нельзя уничтожать цитату пользователя или полезное предупреждение. Самостоятельное положительное утверждение «не имеет аналогов / нет ни у кого» надо заменить нейтральным предупреждением, чтобы ответ не стал пустым. Помни: «нет аналогов» НЕ совпадало с прежним regex, не выдумывай примеры.
2. Не утверждай, что в справке нет лимита, если функцию вообще не снабдили справкой. Отдели практическую рекомендацию от официальной нормы. Нельзя оставлять неподтверждённое «Pinterest рекомендует 80–100 символов» рядом с опровержением.
3. Проверять оговорки внутри того же абзаца, а не по всему ответу. CTA-оговорка не должна приклеиваться к спаму/описанию длины; требуется вердикт именно о призыве/фразе.
4. Для длины Codex отдельно добавляет проверенный источник и прямой ответ по лимитам. Твоя задача — безопасный запасной барьер в ответе LLM: не заявлять факты о содержимом источника. Любые широкие regex-эвристики явно ограничить.
Верни один компактный Python-код плюс 5–8 входных/ожидаемых регрессионных примеров. До 1000 слов. Без новых библиотек и архитектуры; проверка 2 известных дефектов плюс отрицания и цитаты обязательна.
