# Маршрутизация моделей GigaChat

Дата проверки: 2 октября 2026 года.

## Что использует приложение

`GigaChatProvider` получает доступные этому ключу модели через `GET /models` и
кэширует ответ на пять минут. Перед каждым запросом `GigaChatModelRouter`
оставляет только модели, которые одновременно:

1. доступны текущему ключу;
2. описаны в локальном каталоге возможностей;
3. поддерживают требуемую задачу;
4. стоят в порядке `GIGACHAT_MODEL_PRIORITY`.

Если API возвращает отсутствие модели, лимит или временную серверную ошибку,
провайдер в том же запросе пробует следующую подходящую модель. Ответ сохраняет
фактически использованную модель и расход токенов.

## Актуальный ключ

Проверка `GET /models` 2 октября 2026 года вернула:

- `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-2-Max`;
- `GigaChat-3-Lightning`, `GigaChat-3-Pro`, `GigaChat-3-Ultra`;
- модели embeddings.

Список нельзя хранить как постоянную истину: права ключа, пакеты и модели
меняются. Источником доступности остаётся API, а каталог в коде ограничивает
назначение задач только подтверждёнными возможностями.

`GET /models` возвращает модели, доступные ключу, но не закрепляет модель за
строкой «бесплатная» или «платная» из кабинета. Остатки пакетов и тарифы —
данные биллинга, которые могут меняться. Поэтому маршрутизатор не выдумывает
баланс: сначала берёт выбранную для диалога модель, затем переключается по фактическому
ответу API, если модель недоступна или исчерпала лимит.

## Возможности и правила

| Задача | Модели | Правило маршрутизации |
| --- | --- | --- |
| Обычный чат | Все шесть генеративных моделей выше | Начинать с `GigaChat-2-Pro`, затем идти по приоритету. |
| Пользовательские и встроенные функции | Все модели GigaChat | Модель только предлагает имя функции и JSON-аргументы. Сервер исполняет исключительно разрешённую функцию после проверки прав и входных данных. |
| Embeddings | Только модели embeddings | Не направлять в текстовый чат; подключать отдельным провайдером при появлении RAG. |
| Vision, audio, image/3D, structured output | Не включены в текущий маршрутизатор | Добавлять только вместе с отдельным контрактом запроса, валидацией ответа и тестами. |

Официальная документация подтверждает поддержку функций всеми моделями GigaChat.
Качество и стоимость различаются. Для диалога Стратега `GigaChat-2-Pro` выбрана
по сравнению 24 сценариев на шести доступных моделях. Метод и расходы записаны
в `docs/ai-knowledge/model-evaluations.md`.

## Настройки

```dotenv
GIGACHAT_MODEL=GigaChat-2-Pro
GIGACHAT_MODEL_PRIORITY=GigaChat-2-Pro,GigaChat-2,GigaChat-3-Lightning,GigaChat-3-Pro,GigaChat-2-Max,GigaChat-3-Ultra
GIGACHAT_AVAILABLE_MODELS_CACHE_SECONDS=300
```

Первая переменная сохраняет совместимость с существующей конфигурацией и
ставится первой. Вторая определяет fallback-порядок. Смена доступности на
стороне GigaChat подхватывается не позднее окончания cache TTL; менять
токен или scope нужно через окружение и перезапуск контейнеров.
