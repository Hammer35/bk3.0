# Памятка агенту: видео по курсу Pinterest

## Репозиторий и цель

- Инструмент: [nexu-io/open-design](https://github.com/nexu-io/open-design), локальная копия `/home/evgen/open-design`.
- Видео собиралось через HyperFrames (локальный HTML-рендер внутри Open Design).
- Цель пользователя: для каждого урока сначала написать и проверить сценарий/текст, затем подготовить подходящие изображения; все ролики курса должны сохранять общий фирменный стиль.
- Нужен достоверный материал: использовать исходный урок как источник, не добавлять неподтверждённые факты, цифры, обещания охвата/кликов/продаж. Тексты и размеры должны оставаться читаемыми.
- Текущая задача сделана только для урока 1.1; остальные уроки не подготовлены.

Следующим урокам следовать `.hyperframes-cache/pinterest-series-style.md`: графитовый фон, тёплый светлый текст, янтарный и синий акценты; крупные засечковые заголовки и простой шрифт основного текста; редакционные иллюстрации в той же палитре; спокойное движение; без звука. Сохранять короткие фразы и один основной тезис на сцену. До генерации картинок сверить текст сценария с исходным уроком.

## Повторный рендер

В этой среде Open Design daemon работал на `http://127.0.0.1:7457`; для HyperFrames был задан путь браузера `HYPERFRAMES_BROWSER_PATH=/opt/google/chrome/chrome` (headless Chrome). Не считать, что daemon/порт обязательно запущены в другой сессии — сначала проверить доступность и запустить по инструкциям Open Design.

Из `/home/evgen/open-design` для существующего проекта запускали:

```bash
OD_DAEMON_URL=http://127.0.0.1:7457 node apps/daemon/bin/od.mjs media generate \
  --project 9840da70-c05d-4c77-bf4a-ffd23379939c \
  --surface video --model hyperframes-html \
  --output pinterest-lesson-01.mp4 \
  --composition-dir .hyperframes-cache/lesson-01
```

Рендер идёт несколько минут. CLI возвращает ID задачи; если она ещё выполняется, продолжать ожидание командой `node apps/daemon/bin/od.mjs media wait <ID>` с тем же `OD_DAEMON_URL`. После завершения проверить файл через `ffprobe` и просмотреть ключевые кадры. Последний подтверждённый рендер: 35.966667 с, 1080×1920, H.264, 30 fps, около 5.05 MB.
