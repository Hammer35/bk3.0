Недельные индексы сравнимы только между ключами одного вызова API (`normalize_against_group=true`); индексы из разных строк таблицы напрямую сравнивать нельзя. Это не количество запросов.

В выборке `monthly` **не обнаружены** `trimmer`, `shaver`, `gift for him`, `gifts for men`, `mens grooming`. Отсутствие в списке трендов не означает отсутствие спроса. Исключены нерелевантные `bearded dragon`, `bearded vulture`, `diy boyfriend gifts`, а также подарки маме.

## Проверка русских формулировок и поводов

- [Яндекс Маркет](https://marketapp.integration.market.yandex.ru/offers/trimmer-dlia-borody-volos-nosa-i-tela-samozatachivaiushchiesia-lezviia/1229126560) использует товарную формулировку «триммер для бороды»; это подтверждает релевантность словосочетания, но не его поисковую частотность.
- [Исследование Яндекса](https://yandex.ru/company/researches/2011/ya_search_2011) показывает новогодний пик поиска подарков в России. Исследование старое, поэтому это подтверждение типовой сезонности, а не текущего объёма спроса.
- [Яндекс Вордстат](https://yandex.ru/support2/wordstat/ru/interface/new) показывает российскую частотность и динамику, но требует авторизации. Текущую частотность этих русских запросов в Вордстате пока не получили. Google Trends при обращении вернул HTTP 429.

## Приоритет для креативов

1. Сейчас: «подарок парню», «триммер для бороды», «уход за бородой».
2. К Новому году: «подарок папе на Новый год», «подарок мужчине на Новый год».
3. Для отдельной идеи: «форма бороды» / «стрижка бороды», только если визуал показывает эту тему.

Для текстов пинов не приписывать триммеру неподтверждённые характеристики.
