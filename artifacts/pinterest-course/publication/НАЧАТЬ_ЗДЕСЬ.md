# Курс «Pinterest для начинающих» — готовый

В этой папке 40 уроков. Каждый урок — одна папка, в ней всё: сам урок и готовые публикации для семи площадок.

## Что лежит в папке урока

```
Урок_01_Что_такое_Pinterest/
  Видео_урока.mp4        полный урок
  Текст_урока.txt        текст урока (озвучка)
  Задание.txt            задание к уроку
  Субтитры_урока.srt     субтитры
  YouTube/     Видео_16x9.mp4 + Видео_16x9.txt, Обложка_A/B/C.jpg, Субтитры.srt
               Shorts_1.mp4 + Shorts_1.txt, Shorts_2.mp4 + Shorts_2.txt (и обложки)
  VK_Видео/    Видео_16x9.mp4 + Видео_16x9.txt, Обложка_A/B.jpg, Субтитры.srt
  VK_Клипы/    Клип_1.mp4 + Клип_1.txt, Клип_2.mp4 + Клип_2.txt (и обложки)
  Rutube/      Видео_16x9.mp4 + Видео_16x9.txt, Обложка_A/B.jpg, Субтитры.srt
  Instagram/   Reels_1.mp4 + Reels_1.txt, Reels_2.mp4 + Reels_2.txt, Карусель_01…NN.jpg + Карусель.txt
  Threads/     Карточка.jpg + Карточка.txt (ветка постов)
  Pinterest/   Пин_A.jpg + Пин_A.txt, Пин_B.jpg + Пин_B.txt (1000×1500), Видеопин.mp4 + Видеопин.txt
```

## Как публиковать

У каждого креатива свой текстовый файл с тем же именем: Пин_A.jpg → Пин_A.txt, Видеопин.mp4 → Видеопин.txt, Shorts_1.mp4 → Shorts_1.txt и так далее. В файле всё только для этого креатива: название, описание, теги (ключевые слова), хэштеги, а где нужно — доска, альтернативный текст, обложки для A/B-теста, комментарий с заданием. Открывается двойным щелчком в Блокноте или любом редакторе; текст под каждым подзаголовком копируется в соответствующее поле площадки.

Тексты на всех площадках разные: ни одна фраза из четырёх слов подряд не повторяется ни между площадками, ни между уроками. Единственное допущение — поисковые фразы урока (например, «как сделать коллаж в пинтерест») могут повторяться внутри одного урока в названии, описании и тегах, потому что именно их ищут люди.

Названия, описания, теги и хэштеги составлены по ключевым словам. Ключевые слова взяты из реальных подсказок поиска YouTube, Google и Яндекса отдельно для каждого урока; самые частые стоят в начале названий и описаний. Тайм-коды в описаниях YouTube, VK Видео и Rutube рассчитаны по субтитрам урока. Задание к уроку на каждой площадке изложено по-своему (закреплённый комментарий, пост, первый комментарий); официальный текст задания — в файле Задание.txt.

Требования площадок, размеры и как делать A/B-проверку названий и обложек — в файле ПРАВИЛА_ПЛОЩАДОК.txt.
