# Реестр источника: требования Pinterest

Статус: candidate — не загружать в RAG без проверки допустимости хранения конкретных материалов.

## Внутренний обзор

- Файл: `BOOSTKLIENT_3_PINTEREST_API.md`
- В нём зафиксированы ссылки на Pinterest Developer Guidelines, официальную документацию API и дата исследования.
- Обзор сам является вторичным рабочим документом; при расхождении приоритет у актуального первоисточника.

## Важное ограничение корпуса

Не копировать в общий корпус результаты Pinterest API, Pins пользователей/конкурентов, metadata или иные Pinterest Materials. Не использовать их для embeddings или обучения без отдельного письменного разрешения и юридической проверки. Scraping Pinterest не использовать как запасной способ сбора.

Правила доступа, хранения и использования Pinterest-данных должны исполняться системно в backend и проверяться на актуальность. RAG может объяснить правило по проверенной разрешённой документации, но не является механизмом авторизации или enforcement.

## Контентная политика и антиспам

Ссылки ниже — отдельные публичные правила/справка, а не материалы из Pinterest API. Их русскоязычные пересказы находятся в `knowledge/pinterest-spam-prevention.md`. Проверено 2026-09-25.

- https://policy.pinterest.com/ru/community-guidelines — раздел «Спам»; страница указывает обновление в мае 2026 и будущую дату вступления объявленных изменений 2026-11-12. Текущая редакция корпуса ограничена периодом до 2026-11-11; проверить новую редакцию до применения после этой даты.
- https://help.pinterest.com/ru/business/article/pin-performance-and-distribution — оригинальность, повторы, контекст и соответствие целевой страницы.
- https://help.pinterest.com/ru/article/rate-limit-blocks — ограничения частоты действий и временные блокировки.
- https://policy.pinterest.com/ru/commercial-and-branded-content-guidelines — оригинальность, ценность, ограничения манипуляций и раскрытие коммерческого контента.
- https://help.pinterest.com/ru/guide/guide-to-creating-pins — предварительная проверка полей Pins.

Русскоязычные выжимки публичных Правил сообщества и справки уже допущены в глобальный RAG с датой актуальности. Pinterest API Materials остаются отдельной категорией и не копируются автоматически. Эти политики входят в критический preflight для генерации и проверки Pin. Перед публикацией отдельным интеграционным слоем проверяются разрешённость инструмента, URL и данные аккаунта. RAG сам по себе не подтверждает выполнение проверок.

Перед добавлением источника записать URL конкретной страницы, дату проверки, разрешённый объём извлечения/хранения, scope и ответственного за обновление.
