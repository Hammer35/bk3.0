# Проверка Стратега с ArkSim

ArkSim играет роль вымышленного пользователя и ведёт короткий диалог с настоящим backend Стратега. Для каждого прогона создаётся отдельная временная тестовая БД; рабочие сессии и данные бизнеса не используются. Симулятор работает через бесплатную модель OpenRouter, ответы Стратега — через настроенный GigaChat и расходуют его токены.

## Запуск

Сценарии: [strategist-arksim-scenarios.json](examples/strategist-arksim-scenarios.json). Для сухой проверки:

```bash
docker compose exec -T web python scripts/run_strategist_arksim.py
```

Для короткого живого прогона с уже настроенными ключами в `.env`:

```bash
docker compose run --rm --no-deps --user root --entrypoint sh web -c 'pip install --quiet --no-cache-dir --root-user-action=ignore -r requirements/eval.txt && python scripts/run_strategist_arksim.py --run --scenarios 3; eval_status=$?; chown -R 1000:1000 /app/var/strategist-eval 2>/dev/null || true; exit "$eval_status"'
```

Ограничение: не больше двух ответов Стратега на сценарий, один диалог на сценарий, один поток. По умолчанию запускаются три сценария, `--scenarios 9` включает все девять. Протоколы, число токенов и итоги проверки критика сохраняются в `var/strategist-eval/<run_id>/`; эта папка игнорируется Git. Для отдельного сценария есть `--scenario-id`; `--min-replies 2` делает отсутствие второго ответа ошибкой прогона.

## Как читать результат

`summary.json` подтверждает число диалогов и ответов и показывает токены GigaChat. `simulation.json` содержит полный диалог. Проверять нужно первый ответ на вопрос, а не только ответ после уточнения. Четыре критерия: ответ по существу, точность и источник, краткость, последовательность в диалоге. Симуляция помогает находить ошибки, но сама по себе не доказывает фактическую точность или качество всех возможных ответов. Подтверждённые провалы добавлять в [набор сценариев](examples/strategist-dialogue-cases.yaml) и [журнал оценок](model-evaluations.md).

Автоматический оценщик ArkSim служит подсказкой, не единственным критерием: в пробном прогоне он дал `goal_completion=1.0` ответу, который на первый вопрос вместо одного шага перечислил несколько действий. Поэтому критичные ответы сверяются с протоколом и официальным источником вручную.

Бесплатный endpoint NVIDIA — пробный и может регистрировать запросы. Использовать его только с синтетическими сценариями, не с реальными данными бизнеса. Модели из списка OpenCode Zen тоже имеют отдельный API и требуют отдельного ключа; выбор модели в редакторе не переключает модель приложения. Текущий адаптер ArkSim вызывает Responses API, а бесплатные модели Zen опубликованы через Chat Completions: для прямой замены симулятора нужен отдельный адаптер. Они не являются моделями эмбеддингов для RAG.
