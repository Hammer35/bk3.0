# Выбор моделей для задач ИИ-стратега

Этот журнал хранит результаты сравнений моделей и статистику по семействам задач. Тестовые вызовы не считаются рабочими обращениями пользователей. Сценарии оценки хранятся в `examples/` и не индексируются в RAG.

## Реестр задач

| Семейство задач | Рабочий объём | Выбранная модель | Статус оценки |
| --- | --- | --- | --- |
| Текстовый диалог Стратега | Не измеряется по типу задачи | `GigaChat-2-Pro` | Сравнены текстовые ответы по 24 сценариям |
| Диалог с вызовом Pinterest или Wildberries | Не измеряется по типу задачи | Общий маршрутизатор, сначала `GigaChat-2-Pro` | Отдельный сравнительный прогон инструментов ещё не проводился |
| Поиск по утверждённым документам RAG | Не измеряется по типу задачи | `EmbeddingsGigaR` локально, NVIDIA резерв | Сравнены три бесплатных маршрута; основной GigaChat проверен после активации пакета |

Рабочий объём нельзя вывести из числа тестовых сценариев. Когда появится учёт типа задачи в рабочих запросах, сюда следует добавлять период и фактическое число запросов без текстов пользователей.

## 2 октября 2026: текстовый диалог Стратега

Задача: отвечать на текущий вопрос по-русски, точно и кратко, учитывать историю и не выдумывать Pinterest-факты. Данные: 24 синтетических сценария из `examples/strategist-dialogue-cases.yaml` (SHA-256 `3dbf9ee17e60b65162a275d99eb561d6b6fd1617304b019b27e0adc37bea9c5e`). Использован системный prompt из `apps/strategist/prompts.py` (SHA-256 `0f167b89c604f30c566a89e77c29ce5086527d95fc2ed4987ce8a589654e2f02`) и одинаковый контекст сценария для каждой модели. Ожидаемые ответы моделям не передавались. Для сценариев с источником передавались фрагменты утверждённых локальных материалов. Лимит ответа — 1200 токенов.

| Модель | Ответов | Ошибок запроса | Вход + выход, токенов | Наблюдение по критичным случаям |
| --- | ---: | ---: | ---: | --- |
| `GigaChat-2` | 24 | 0 | 15 538 | Подтвердила неподтверждённую норму «10 пинов в день» как совет Pinterest |
| `GigaChat-2-Max` | 24 | 0 | 16 978 | Без источника сформулировала правило хранения данных Pinterest API |
| `GigaChat-2-Pro` | 24 | 0 | 16 364 | Лучший баланс краткости и точности в ручном сравнении ключевых случаев; предложила неподтверждённые «1–3 пина в день» |
| `GigaChat-3-Lightning` | 24 | 0 | 15 544 | Назвала неподтверждённые 90 дней хранения API-данных и частоту публикаций |
| `GigaChat-3-Pro` | 24 | 0 | 31 024 | Чаще разрастается в советы и тоже назначает неподтверждённую частоту |
| `GigaChat-3-Ultra` | 24 | 0 | 39 711 | Самый большой расход; добавляет неподтверждённые детали правил и товара |

Всего: 144 ответа, 0 ошибок запроса, 135 159 списанных токенов. Расход совпал с изменением баланса API по пакетам. Денежная стоимость не установлена: доступный баланс показывает токены, а применимый тариф к нему не подтверждён. Задержки и доля успешных ответов по полной шкале 0–8 не измерялись; заключение основано на ручном разборе ключевых случаев.

Решение: `GigaChat-2-Pro` первой в маршруте обычного чата, затем существующий fallback-порядок. Это предварительный выбор для текстового диалога. В сравнении не проверялись живой поиск RAG, вызовы функций и полный backend-маршрут; для этих задач нужны отдельные сценарии. Повторить оценку после изменения prompt, контекста, набора инструментов или появления новых моделей.

## 2 октября 2026: ручная проверка через интерфейс после исправления маршрута

Пользователь повторил 4 вопроса в одной сессии чата. Ошибочный ответ со списком подключённых профилей больше не появился. Ручная оценка: 1 ответ прошёл, 2 частично прошли, 1 провалился. Это выборка из проверочного набора, а не статистика рабочих запросов. Фактическая модель, токены, задержка и применённые RAG-фрагменты для этих четырёх ответов не зафиксированы; результат нельзя приписать одной модели.

- Частично: ответ о ежедневной частоте публикаций без ссылки категорично утверждает отсутствие официальной нормы и приписывает Pinterest рекомендацию о регулярности.
- Прошёл: ответ о 12 исходящих кликах прямо говорит, что по ним нельзя узнать количество заказов.
- Частично: ответ о росте переходов и заказах не выдумывает числа, но не говорит прямо, что причина роста неизвестна без статистики.
- Провал: ответ о Правилах сообщества объявляет любую публикацию «связанного с» перечисленными темами запрещённой, не различая контекст, удаление и ограничение распространения; ссылка на официальный источник не дана.

После оценки уточнены правила ответа для неподтверждённых отрицательных утверждений и вопросов о причинах метрик. Вопросы о Правилах сообщества теперь получают действующий утверждённый локальный источник и ссылку; для них не запускается поиск по эмбеддингам. Следующий шаг — повторить спорные вопросы с фиксацией модели и источников. Платных вызовов в рамках этой записи не выполнялось.

Позднее логи пяти отдельных ручных сессий показали сбой получения эмбеддингов (`GigaChatProviderError`) при успешных ответах чата через локальный запасной поиск. Два коротких диагностических запроса к `EmbeddingsGigaR` также завершились ошибкой; второй раскрыл HTTP `402`. По документации GigaChat это означает исчерпание доступных токенов запрошенной модели. Расход этих неуспешных вызовов не установлен. До восстановления квоты результаты ручной проверки не следует считать проверкой обычного пути RAG.

Добавлен локальный поиск по утверждённым фрагментам базы знаний с передачей ссылок на источники. После HTTP `402` повторные вызовы эмбеддингов блокируются на 5 минут, а чат использует локальный поиск. Обычный семантический поиск возобновится после восстановления квоты; качество нового запасного пути в ручном диалоге ещё не проверено. Дополнительных платных запросов при этом изменении не делали.

## 3 октября 2026: бесплатные эмбеддинги для RAG

Задача: найти нужный утверждённый документ по русскому вопросу. Сравнение проводилось на одинаковых семи синтетических вопросах и 30 фрагментах из семи документов. Это оценка поиска, не качества ответа GigaChat. Рабочий объём запросов RAG не измеряется. Текущая модель чата и её маршрутизация не менялись.

| Модель OpenRouter | Первый найденный документ | Нужный документ в первых трёх | Результат |
| --- | ---: | ---: | --- |
| `nvidia/nemotron-3-embed-1b:free` | 6/7 | 7/7 | 2048 измерений, 6968 входных токенов в сравнении |
| `nvidia/llama-nemotron-embed-vl-1b-v2:free` | 7/7 | 7/7 | 2048 измерений, 7047 входных токенов в сравнении |
| `liquid/lfm-2.5-embedding-350m:free` | Не измерено | Не измерено | Короткий запрос работает, но текущий фрагмент на 957 токенов получил HTTP 400: максимум модели — 512 токенов |

Выбрана `nvidia/llama-nemotron-embed-vl-1b-v2:free`. Ею пересчитаны 7 документов и 30 фрагментов (6916 входных токенов). На сохранённом индексе семь релевантных вопросов снова нашли ожидаемый документ первыми; три посторонних вопроса дали максимум сходства 0,1698, минимум у релевантных — 0,3113. Для OpenRouter установлен порог 0,25. Прямой вызов рабочего `search_knowledge` вернул документ об аналитике на вопрос о заказах по исходящим кликам и пустой результат на вопрос о супе. Отдельные токены и задержки этих последних проверок не фиксировались; p50/p95 и стоимость в деньгах не измерялись. Бесплатность маршрута указана провайдером, списание по кабинету не сверялось.

Ограничения: семь вопросов и три отрицательных примера слишком малы для вывода о стабильном качестве. Бесплатный NVIDIA endpoint заявлен как пробный и предупреждает о регистрации запросов; перед использованием с конфиденциальными данными бизнеса нужен другой маршрут. Повторить оценку при изменении корпуса, модели, порога или условий бесплатного API.

## 3 октября 2026: основной GigaChat, резерв NVIDIA

После активации пакета Embeddings пробный вызов `EmbeddingsGigaR` успешно вернул один вектор на 2560 измерений за 7 входных токенов. Локальный индекс пересчитан для 7 документов и 30 фрагментов: 6187 входных токенов GigaChat. Ранее рассчитанные 30 NVIDIA-векторов сохранены как резерв без повторного индексирования. Для вопроса об исходящих кликах и заказах оба поиска вернули первым документ об аналитике: GigaChat — сходство 0,789, NVIDIA — 0,468. Проверка проведена на одном запросе; медиана, p95 и денежная стоимость не измерялись. Основным выбран GigaChat; NVIDIA вызывается только при ошибке основного API и только там, где явно задан резерв. Повторить оценку при изменении корпуса, порога или условий резервного провайдера.
