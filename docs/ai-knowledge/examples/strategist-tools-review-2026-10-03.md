# Инструменты Стратега — 3 октября 2026

## Найденный и исправленный дефект

Успешный HTTP-запрос инструмента мог вернуть JSON-массив. В tool-loop
`respond_to_message` результат использовался как словарь (`result.get`)
без проверки типа: это приводило к HTTP 500. Regression-тест сначала упал
с AttributeError, после исправления возвращает сохранённый русский отказ
`data-read/read-error` и не вызывает модель повторно.

Также исправлена статистика: запрос модели до ошибки инструмента расходует
токены, теперь этот usage сохраняется в AIMessage, а не теряется как ноль.

## Проверки

`apps/strategist/test_tool_acceptance.py` содержит 11 сценариев через
авторизованный AJAX chat, сохранённые AIMessage и messages_html:

- Чужой business/account_key — запрос источника не выполняется.
- Недостаточные scopes — запрос не выполняется.
- Неверные arguments и options — безопасный отказ.
- Неизвестная функция `publish_pin` — безопасный отказ без исполнения.
- JSON array и null — неподдерживаемый формат, без HTTP 500.
- REAUTH_REQUIRED — источник не читается.
- Недоступный Pinterest — отказ без генерации выводов.
- Неожиданное исключение — детали не попадают в ответ.
- Валидный result — передаётся модели как function JSON; usage двух вызовов
  суммируется. При ошибке сохраняется usage первого вызова.

Внешние GigaChat/Pinterest вызовы в этом наборе замоканы. Это доказательство
обработки указанных случаев, не проверка реального провайдера или свободного
текста модели. OpenCode TASK-014 не принят; причины в REVIEW-014.md.
Настройки, .env, main и публикация не менялись.
