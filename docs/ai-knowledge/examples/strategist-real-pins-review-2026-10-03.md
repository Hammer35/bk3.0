# Пины и топ исходящих кликов — 3 октября 2026

## Реальный API

Два CONNECTED-профиля локального бизнеса. По одному GET /pins (page_size5)
и /user_account/analytics/top_pins (num_of_pins5) на профиль:4HTTP200.
Обычные списки имеют bookmark; первые страницы не объявляются полным
количеством пинов. Топ аналитики — ограниченный рейтинг по OUTBOUND_CLICK,
а не полный каталог. Приватные ID/значения/ответы не включены в Git.

## Найденные ошибки

Первичный GigaChat передавал limit вместо num_of_pins (2отказа доAPI).
После уточнения описания инструмента модель передавала OUTBOUND_CLICKS
в metric_types (2реальных HTTP400 +1диагностический400). После исправления
кода метрики оба запроса успешны, числа верные, но модель не дала
запрошенные ссылки и не предупредила о задержке данных.

Описание инструмента уточнено по официальной схеме:
https://github.com/pinterest/api-description/blob/main/v5/openapi.yaml
Рейтинг по исходящим кликам с одним профилем и заданным периодом теперь
формируется напрямую из API. Это числовой отчёт; объяснения причин и
сравнения не включены в этот узкий маршрут.

Ссылки строятся только из числовых pin_id по документированному формату:
https://help.pinterest.com/en/business/article/find-ids-in-ads-manager
Проверяются data_status READY, целое неотрицательное значение, формат
ответа, число результатов1–50. PROCESSING/отсутствие данных не становятся0.
latest_available_timestamp сравнивается с концом периода вUTC; при задержке
ответ предупреждает, что рейтинг предварительный.
