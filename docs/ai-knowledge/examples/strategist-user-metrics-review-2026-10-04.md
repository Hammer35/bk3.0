# Числа пользователя — 4 октября 2026

## Изменение

`user_metrics_answer` в отдельном модуле разбирает ограниченный набор
однозначных записей: счётчики показов/переходов/заказов/сохранений,
«было/стало», «с/до», неизменный счётчик, явные поля двух периодов.
Числа взяты только из текущего сообщения; ответ помечен «По твоим данным»,
не выдаётся за прочитанный Pinterest API или независимую проверку продаж.
Пробелы тысяч поддерживаются. Отрицательные/дробные счётчики, проценты
вместо числа событий, непонятный порядок и принадлежность уточняются.

Доли и процент изменения вычисляет код. Нулевой знаменатель не даёт0%.
Заказы считаются связанными с переходами только условно, при подтверждённой
атрибуции. Неравные/неподтверждённые окна не объявляются трендом.
Малая выборка не получает выдуманного вердикта о значимости; совпадение
частоты публикаций и переходов не устанавливает причину.

Для этих коротких ответов модель не вызывается: предыдущий платный прогон
показал ошибки при свободном объяснении. Это сознательное уточнение плана:
сначала надёжный расчёт и короткое объяснение кодом, а не повторный риск
искажения проверенных чисел моделью. Обычный диалог, RAG и настройки
GigaChat-2-Pro сохраняются. Необработанные форматы не обещаем понимать:
аналитический ввод уточняем, остальные задачи продолжают обычный маршрут.

## Ограничения

Это ограниченный безопасный разбор, не универсальное понимание любого
текста. Не связывает показатели разных аккаунтов/источников по догадке,
не извлекает новые цифры из ответов ассистента, не доказывает причины,
устойчивую конверсию или качество товара. Произвольная многоходовая
интерпретация и остальные семейства чата требуют отдельных проверок.
