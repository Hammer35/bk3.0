Два подключённых профиля локального бизнеса. Только чтение официального
Pinterest API, без изменений Pinterest, публикации или перенастройки аккаунтов.

скрипты и обезличенные traces хранятся в ignored runtime; ответы чата —

## Найденные дефекты и исправления

1. JSON array вместо объекта в прямом чтении досок вызывал AttributeError
   и500. Регрессия воспроизвела сбой; добавлена проверка типа, теперь
   чат выдаёт безопасное сообщение без выдуманного нулевого списка.
2. Реальный GigaChat на вопрос о числе подписчиков первого профиля выбрал
   другой account_key. Защита остановила запрос; данные чужого профиля
   не прочитаны. Второй ответ модели верный, но для простого числа LLM лишняя.
   Добавлен узкий маршрут текущего счётчика: GET /user_account → follower_count.
   Поле документировано в официальном Account schema:
   https://github.com/pinterest/api-description/blob/main/v5/openapi.yaml
   Только целое неотрицательное число; null/bool/string/отсутствие поля
   не превращаются в0. Списки, сравнения и объяснения остаются в tool loop.
