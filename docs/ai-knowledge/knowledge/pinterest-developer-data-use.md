# Данные Pinterest API: что говорят правила для разработчиков

## Короткий ответ о сроке хранения

В проверенных официальных Правилах для разработчиков Pinterest нет универсального срока вроде «90 дней», в течение которого можно хранить все данные API. Нельзя выдавать такое число за правило без отдельного актуального источника. Вопрос о конкретном виде данных нужно разбирать по его категории и применимым условиям доступа.

## Подтверждённое ограничение

В разделе «The basics» Pinterest указывает: кроме сведений аналитики рекламных кампаний собственного аккаунта или аккаунта с явно предоставленным доступом, информацию, полученную через материалы Pinterest, включая API, хранить нельзя; вместо этого следует заново обращаться к API каждый раз, когда она нужна. Это правило о допустимости хранения, а не о числе дней. Применение исключения к конкретному набору данных нельзя предполагать без проверки.

Правила также требуют авторизации владельца аккаунта, запрещают передавать или продавать данные API третьим лицам, использовать неразрешённый scraping вместо API и использовать материалы Pinterest для обучения ИИ без явного разрешения. Для приложения нужно отдельно проверить актуальные Developer & API Terms и условия его доступа; этот краткий документ не заменяет такую проверку.

Источник: [Pinterest Developer guidelines](https://policy.pinterest.com/en/developer-guidelines), разделы «The basics» и «What not to do», проверено 2026-10-02 UTC.
